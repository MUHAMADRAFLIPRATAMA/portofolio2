Detektor Pesan Penipuan adalah aplikasi machine learning yang membantu mengklasifikasikan pesan SMS atau WhatsApp menjadi normal atau penipuan, lengkap dengan tingkat keyakinan prediksi.

Pipeline

Dari teks mentah
menjadi sinyal risiko.

01 / CLEAN

Preprocessing

Pesan dinormalisasi, URL dan nomor telepon diganti token, lalu duplikat dibersihkan.

02 / LEARN

TF-IDF

Unigram dan bigram mengubah pola kata dalam pesan menjadi fitur numerik untuk model.

03 / PREDICT

Logistic Regression

Model menentukan label NORMAL atau PENIPUAN dan mengembalikan confidence score.

Project notes

Built for clarity,
not false certainty.

Proyek ini menyediakan antarmuka command line dan web sederhana tanpa framework tambahan. Model dilatih dengan dataset pesan berlabel, dievaluasi menggunakan accuracy, precision, recall, dan F1-score, lalu disimpan dalam format Joblib agar bisa digunakan kembali.
